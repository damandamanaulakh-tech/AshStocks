EPS × P/E · Paper target planning

3, 9 and 12 month sell targets

Calculated valuation scenarios, not verified forecasts or AshStock SELECT signals. Assumptions must be reviewed before activation. Saving assumptions does not create an order or change a holding's sell target.

12-month base range = normalised annual EPS × base P/E low / high. Mid = (low + high) ÷ 2.

3 / 9-month marker = reference price + (12-month value − reference price) × months ÷ 12.

Bear / optional bull sensitivity = scenario EPS × scenario P/E. Upside = (target ÷ reference price − 1) × 100.

Shorter horizons are interpolated markers, not independent predictions. Dates are measured from the reference date. Scenarios exclude dividends, taxes and costs; bear values are not guaranteed floors.
